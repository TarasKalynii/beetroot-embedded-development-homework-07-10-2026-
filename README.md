# Embedded Development — домашнє завдання 07.10.2026

Проєкт для ESP32-S3 на Arduino / PlatformIO: вимірювання часу ввімкнення та вимкнення реле за зміною стану його контакту.

## Робота програми

- Керування реле через GPIO4, зчитування контакту через GPIO6 з `INPUT_PULLUP` (COM → GND, NO → GPIO6).
- Фіксація зміни контакту через переривання `CHANGE` і перевірка стану після 5 мс без нових фронтів.
- Пауза між перемиканнями — 1 с; таймаут очікування контакту — 100 мс.
- Serial Monitor на швидкості 115200 виводить час `ON`, `OFF` і середні значення в мікросекундах.

## Збірка

Відкрити проєкт у VS Code з розширенням PlatformIO та виконати **Build**, або запустити:

```sh
pio run
```
